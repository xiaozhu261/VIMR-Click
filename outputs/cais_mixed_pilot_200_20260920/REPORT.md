# CAIS 合成纠错点击试验报告

日期：2026-09-20

## 结论

本次试验生成了 200 个合成交互任务、905 次点击，并与原有真人训练数据混合训练。合成轨迹未参与认知头监督，真人验证集和测试集保持不变。

在相同的 112 个真人测试点击上，Mask IoU 从纯真人训练的 0.6056 提升到 0.6649，绝对提升 0.0593，相对提升约 9.8%。负点击子集 IoU 从 0.6105 提升到 0.6609。

## 合成数据

| 指标 | 数值 |
|---|---:|
| 合成任务 | 200 |
| 唯一图像 | 200 |
| COCO 类别覆盖 | 80/80 |
| 合成点击 | 905 |
| 正点击 | 670 |
| 负点击 | 235 |
| 负点击比例 | 25.97% |
| 平均点击数/任务 | 4.525 |
| 最终平均 IoU | 0.8647 |
| 最终中位 IoU | 0.9028 |
| 最终 IoU >= 0.95 | 40 个任务 |
| 最终 IoU >= 0.90 | 103 个任务 |
| 最终 IoU < 0.75 | 24 个任务 |

生成策略：首次正点取 GT 最大连通区域的距离中心；后续在漏分区域生成正点，在多分区域生成负点；负点目标比例为 25%；每个任务最多 5 次点击。

这 200 张图像与原始人工项目中的 372 个 COCO 图像 ID 完全不重叠。

## 认知信号隔离

- 所有合成记录标记 `source=synthetic`。
- 所有合成记录标记 `cognitive_supervision=false`。
- 合成轨迹为空，`trajectory_valid_mask` 全为 false。
- 认知归一化参数只由 552 条真人训练点击拟合。
- 合成样本只优化 Mask 与 IoU 相关目标；认知损失为零。
- 验证集和测试集仍分别为 124/112 条真人点击。

## 训练结果

| 模型 | 最佳轮次 | 真人验证 IoU | 真人测试 IoU | 测试质量 MAE | 测试认知 MAE |
|---|---:|---:|---:|---:|---:|
| 仅真人数据 | 8 | 0.6226 | 0.6056 | 0.2477 | **0.1587** |
| 真人 + 200 合成任务 | 7 | **0.6762** | **0.6649** | **0.1923** | 0.1622 |
| 差值 | - | +0.0536 | +0.0593 | -0.0555 | +0.0035 |

Mask IoU 越高越好；MAE 越低越好。合成数据显著改善了分割与质量预测，但没有改善认知头，符合“认知头只从真人行为学习”的预期。

## 正负点击分组

| 测试子集 | 样本数 | 仅真人 IoU | 混合训练 IoU | 提升 |
|---|---:|---:|---:|---:|
| 当前点击为正点 | 101 | 0.6051 | 0.6653 | +0.0602 |
| 当前点击为负点 | 11 | 0.6105 | 0.6609 | +0.0504 |

真人测试集的负点只有 11 条，因此负点增益方向明确，但样本量仍不足以给出高置信度结论。

## 与冻结基线比较

| 模型 | 验证 IoU | 测试 IoU |
|---|---:|---:|
| 冻结 EfficientViT-SAM-L0 | **0.6784** | **0.7270** |
| 真人 + 合成 CAIS | 0.6764 | 0.6645 |
| CAIS - 基线 | -0.0021 | -0.0625 |

混合 CAIS 在验证集上已经基本追平冻结基线，但测试集仍有 6.25 个百分点差距。

## 关于多模态大模型

本批次没有调用多模态大模型。原因是 COCO 已提供可靠类别和像素级 GT；在这一阶段直接由 GT 与模型预测的差异生成点击，更精确、可复现，也不会引入坐标幻觉。多模态模型更适合下一阶段处理没有 GT 的新图像：定位目标、给出候选框、识别模糊/遮挡样本并做语义质检。

## 下一步建议

保持真人验证/测试集不变，将合成规模扩到约 1,000 个实例之前，先测试真人/合成分层采样，例如每个 epoch 固定真人与合成点击比例为 1:1。这样能降低合成数据占比过高造成的分布偏移，同时继续补充负点击与长尾类别。
